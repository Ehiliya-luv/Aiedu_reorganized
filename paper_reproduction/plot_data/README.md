# Paper-facing aggregate inputs

These CSV files contain only model-level or task-level aggregate values used to
rebuild the published result figures. They contain no case text, medical
record, model output, Judge reason, API credential, or absolute local path.

The three Question panels use the manuscript terms **answer-key accuracy**,
**option-set validity**, and **stem clarity**. The separate preference and
reasoning tables are aggregate summaries for their respective figures.

`workflow_time_summary.csv` is an aggregate comparison table. It contains no
raw questionnaire or per-case timing record.
